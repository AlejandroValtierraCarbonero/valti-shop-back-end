# valti-shop-back-end
Proyecto de prueba. Gestión de una tienda. Backend del proyecto

## Stack
* El proyecto se desarrolla en C# .NET Core y siempre se mantendrá con la última versión dsiponible del SDK
* Para la conexión con la base de datos se usará EntityFrameworkCore

## Conventions
* Se seguirán las convenciónes proporcionadas por la doucmentación de MS: https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions
* El código estará en inglés
* Se segurián los principios Clean Code y SOLID

## Arquitectura
Este proyecto consiste en una API REST con una arquitectira DDD con capa de presentación, dominio, aplicación y persistencia
